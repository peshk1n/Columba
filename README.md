# Columba

Columba — Android-приложение для тестирования и демонстрации работы собственного протокола гарантированной передачи данных по ненадёжному каналу связи.

## Описание

Приложение позволяет запускать симуляцию передачи файлов между отправителем и получателем внутри устройства Android без использования реальной сети. В качестве транспортного уровня используется нативная C++ библиотека с реализацией протокола Go-Back-N.

Поддерживаются различные режимы тестирования канала, включая потери, повреждения и задержки пакетов, что позволяет анализировать поведение протокола в нестабильных условиях.

## Возможности

- выбор файла для передачи
- настройка параметров тестового канала
- симуляция потерь, повреждений и задержек пакетов
- отображение прогресса передачи и основных метрик
- сохранение полученного файла
- интеграция с нативной C++ библиотекой через JNI

## Технологии

- Java
- Android SDK
- JNI
- C++ 
- CMake
